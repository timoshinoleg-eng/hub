Оператор: **[Полное наименование]**, ИНН **[ИНН]**, адрес: **[адрес]**.

## 1. Какие данные обрабатываются

| Данные | Цель |
|---|---|
| Анонимные технические события: игра, действие, значение, время, стартовый параметр | работа и оценка продукта |
| Подписанная строка MAX WebApp `initData` | кратковременная серверная проверка подлинности пользователя после явного consent/действия, требующего identity |
| HMAC-псевдоним MAX `user_id` | связанная статистика только после consent |
| MAX `user_id` подписчика | отправка запрошенного пользователем уведомления |

До consent analytics не содержит MAX identity и не сохраняет `initData`. Signed `initData` используется сервером для проверки подписи/свежести; его поля, кроме необходимого результата проверки identity, не должны сохраняться в analytics storage.

Сервис не запрашивает телефон, e-mail, геолокацию или телефонную книгу через Mini App.

## 2. Цели

- предоставление доступа к мини-играм;
- измерение технических и продуктовых метрик;
- отправка уведомления пользователю, который явно запросил такое уведомление;
- обеспечение безопасности и проверка подлинности запросов MAX Mini App.

## 3. Согласие и отзыв

Действия, требующие сохранения MAX `user_id` или связанной pseudonymous analytics, выполняются только после явного пользовательского действия/согласия в соответствующем интерфейсе.

До этого игровые события являются анонимными и не содержат MAX identity.

Пользователь может запросить удаление связанных данных командой `/forget` в боте или через **[контакт оператора]**. Укажите здесь фактический срок исполнения запроса: **[срок]**.

- хостинг/ЦОД: **[провайдер, регион]**;
- база данных: **[провайдер, регион]**;
- сроки хранения анонимных событий: **[срок]**;

Production-конфигурация приложения рассчитана на Postgres; локальный JSON storage является dev/test режимом и не предназначен для production.

## 6. Несовершеннолетние

Сервис имеет возрастную маркировку **[указать фактическую]**. До запуска согласуйте формулировки и правовое основание обработки данных несовершеннолетних с профильным специалистом; техническая невозможность определить возраст сама по себе не заменяет такую оценку.

## 7. Меры защиты

Текущие технические меры включают:

- HTTPS для production Mini App/API;
- серверную HMAC-проверку MAX `initData` и freshness check;
- отсутствие доверия к `initDataUnsafe` для backend identity;
- HMAC-псевдонимизацию связанной аналитики;
- отдельный Bearer secret для административных HTTP-endpoints;
- fail-closed список администраторов бота;
- Postgres-only guard в production;
- запрет коммита локальной JSON БД и секретов.
